# Bundled dashboard font

Plus Jakarta Sans (normal, variable weight 200–800), downloaded on 6 November 2026 from the Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/plusjakartasans

The unmodified TrueType font is distributed under the SIL Open Font License 1.1. Keep `OFL-Plus-Jakarta-Sans.txt` with the font when redistributing the application.

`src/index.css` declares the font face, and `index.html` preloads it. Dashboard text and numeric values share this font; tabular numerals align numbers without switching font families. Material Symbols remains a separate icon font.
